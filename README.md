# Retail Sales Analysis Dashboard

## 📊 Project Overview

This project is a beginner-level **Retail Sales Analysis Dashboard** created using **Microsoft Power BI, Excel, Power Query, and Power Pivot**.

The goal of the project is to analyze retail sales data and identify useful insights related to sales, profit, product performance, categories, regions, and monthly sales trends.

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data preparation and initial analysis
- **Power Query** – Data cleaning and transformation
- **Power Pivot** – Data modeling and measures
- **Microsoft Power BI** – Data visualization and dashboard creation

## 🧹 Data Preparation

The dataset was prepared using Excel and Power Query.

The main data-cleaning steps included:

- Checking and correcting data types
- Handling date-related data issues
- Removing duplicate records
- Creating a calculated **Profit Margin** column
- Preparing the cleaned dataset for analysis

Power Pivot was then used to create measures for key metrics such as:

- Total Sales
- Total Profit
- Total Quantity

## 📈 Power BI Dashboard

The dashboard contains:

### Key Performance Indicators

- **Total Sales:** 1.10M
- **Total Profit:** 132.52K
- **Total Quantity:** 19K

### Visualizations

- **Sales by Category**
- **Profit by Region**
- **Monthly Sales Trend**
- **Top 10 Products by Sales**

### Interactive Filters

Users can filter the dashboard using:

- Year
- Category
- Region

The visuals update based on the selected filters, allowing users to explore different parts of the dataset.

## 🔎 Key Insights

Some observations from the dashboard include:

- **Technology** generated the highest sales among the three categories.
- The **East region** generated the highest profit.
- Sales varied considerably throughout the year, with **November and December** showing the highest monthly sales.
- The **Canon imageCLASS 2200 Advanced Copier** was the highest-selling product among the Top 10 products shown.

## 📷 Dashboard Preview

The final dashboard provides a single-page overview of retail sales performance, combining KPIs, interactive filters, charts, and product-level analysis.

## 🎯 Learning Objectives

This project was created to practice:

- Excel data handling
- Data cleaning with Power Query
- Basic Power Pivot data modeling
- Creating measures
- Building Power BI dashboards
- Using slicers and interactive filters
- Creating business-focused visualizations
- Extracting insights from sales data

## 🚀 Conclusion

This project demonstrates a basic end-to-end data analysis workflow:

**Excel → Power Query → Power Pivot → Power BI**

It was created as a practical project to develop foundational skills in data cleaning, data modeling, visualization, and business intelligence.
